# Chronology of deviations and later checks

This document preserves the original [Phase 7 pre-analysis specification](preanalysis_specification.md) and [historical decision log](decision_log.md); it does **not** relabel later work as originally pre-specified. The frozen Phase 9 sample, listed-DKK log-price outcome, primary 800 m/10-minute access definitions, model outputs and stored folds were not changed by the later sensitivities. Detailed timing classifications are in the [robustness registry](robustness_registry.md).
