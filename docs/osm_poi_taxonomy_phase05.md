# Phase 5 OSM destination specification (frozen before price modelling)

Version: `phase05_v2`. This is a pre-model, tag-based definition. The initial `v1` included `historic=memorial`; inspection of the new extract showed 266 memorial-tagged objects, many plaques, stones and Stolpersteine. Before any price analysis, `v2` excluded memorial-only objects as weak proxies for major cultural/tourist opportunities. The PBF remains unchanged and the broader raw tag selection preserves them for audit. No price data, model score, or accessibility threshold was used to choose tags.

| Category | Inclusion tags | Exclusions / interpretation |
| --- | --- | --- |
| `food_social` | `amenity=restaurant,cafe,bar,pub` | Excludes takeaway-only, shops, fast food, hotels; one distinct OSM destination per real-world named/unnamed place. |
| `cultural_tourist` | `tourism=museum,gallery,attraction,viewpoint`; `amenity=theatre`; `historic=monument,castle,palace` | Excludes memorial-only plaques/stones, broad parks/leisure, historic buildings without one of these tags, and generic tourism accommodation. |
| `station` | Named `railway=station,halt`, or named `public_transport=station` with `train=yes`, `subway=yes`, or `station=subway,light_rail,train` | Excludes subway entrances, tram/bus-only stops, unnamed platforms and generic public-transport stops. Mode label is metro, urban rail or other rail; all enter the single nearest-station measure. |

The earlier Overpass archive showed 897 restaurants, 995 cafes, 555 bars, 102 pubs, 83 museums, 51 galleries, 77 attractions, 39 viewpoints, 59 theatres, 60 railway stations, 43 railway halts and 67 subway entrances in its smaller request box. Historic features were incompletely requested there, so their count was not used to decide inclusion. The new BBBike PBF covers a larger boundary; the report gives its actual returned counts. Source tags can describe more than one category; a destination may legitimately appear in both food/social and cultural/tourist categories when the tags support both.

The immutable PBF is read with GDAL's OSM driver using `config/osmconf_phase5.ini`, a recorded tag filter, and all five geometry layers. `raw.osm_phase5_elements` retains selected GeoJSON features and full returned tags; the PBF itself is the recoverable source. For points, use the OSM node coordinate. For ways and relations, use `ST_PointOnSurface` on the GDAL geometry, in EPSG:4326 then project to EPSG:25832. This representative point is **not an entrance**. A later network analysis must use the *same canonical destination point set* for a fair comparison, or declare a different-destination sensitivity explicitly.

Deduplication is deterministic and within category. Candidates sharing a nonempty normalized name are merged only within 35 m (food), 60 m (culture) or 250 m (station). Candidates sharing a Wikidata identifier may merge within 100 m, 150 m or 500 m respectively. Spatial proximity alone never merges distinct names without shared Wikidata. Nodes are preferred over ways, then relations, then lower OSM ID. The candidate table preserves every source reference, canonical key and reason; canonical tables retain merged references and counts. These rules target node–polygon duplicate businesses and station buildings/platforms without indiscriminately collapsing neighbouring venues.

Euclidean distances use `geom_25832` (ETRS89 / UTM zone 32N, EPSG:25832). Count radii are exactly 800 m primary and 1,200/1,600 m sensitivity. Listing source coordinates are provider-anonymised, so measures are approximations. A source-edge flag is retained separately for counts and nearest station; missing/incomplete coordinates are not converted to zero counts.
