# Final methods visualisation — saved spatial validation designs

Date: 2026-09-29. This is a **methods-display cleanup only**. No fold assignment was regenerated; no model was fit, tuned, or rerun. Figures and tables are generated by `make validation-visuals` from read-only `analysis.cv_assignments`, `analysis.cv_buffer_exclusions`, the official PostGIS municipalities/CV areas, and already-saved Phase 9/10 performance tables. The existing Phase 9 artifact and CV-assignment hashes are checked before and after output generation.

## What each validation design asks

[The three-panel schematic](../outputs/figures/final/figure_validation_designs.png) uses **synthetic symbols**, not real Airbnb point locations. Random five-fold CV assigns listings individually, so training and test listings may be neighbours; it is an interspersed benchmark for prediction in a familiar spatial mix, not a strong test of transfer to a new neighbourhood. Geometric-block CV assigns whole **1.5 km × 1.5 km** cells to one of five folds. All listings within one spatial block are assigned to the same fold. Blocks are not folds: multiple blocks belong to each fold. Neighbouring cells can still fall in different folds, so this is a non-administrative spatial robustness check, not a guaranteed 1.5 km train–test gap.

Leave-one-area-out (LOAO) CV withholds **one complete official area** at a time. There are **11 held-out groups: ten Copenhagen districts plus Frederiksberg municipality**. No single district was selected as *the* test district; each group is test data exactly once. Pooled out-of-fold (OOF) predictions combine all 11 held-out runs. This is the primary **reported unseen-area geographic test** in Phase 9, which asks about transfer to an official district or the municipality-sized Frederiksberg proxy. Areas can touch, so training points just across an official border can still be close to test points. In buffered LOAO, the test area is unchanged, but the saved `analysis.cv_buffer_exclusions` removes training listings within **500 m or 1,000 m** of its polygon in EPSG:25832. That asks a more spatially separated, harder extrapolation question. It does not create new test folds.

These schemes answer related but different prediction questions. Random CV can be optimistic under spatial autocorrelation; geometric blocks reduce within-cell mixing without using administrative boundaries; LOAO tests transfer to an unseen named area; buffered LOAO adds an explicit separation gap. One scheme's lower RMSE is **not** proof that it is universally more valid or that a different model should become primary. The earlier Phase 7 five-fold **1 km** grid assignment remains saved separately; it was not the Phase 9 reported LOAO comparison and is not relabelled here. Some Phase 8 prose calls that earlier split “primary” in the pre-analysis freeze, whereas the user-directed Phase 9 reporting uses LOAO as its principal unseen-area test. This report preserves that chronology rather than rewriting it.

## Actual 1.5 km block map

[The appendix map](../outputs/figures/final/appendix_geometric_block_cv.png) is **not** a schematic. It reconstructs each square's geometry directly from the saved `block_1500m_id` integer grid indices (`floor(EPSG:25832 x/1500):floor(y/1500)`), uses the stored `block_1500m_fold` 1–5 value, and clips the coloured square to the official Copenhagen–Frederiksberg union **for display only**. The municipality outlines are overlaid; no individual listing points or identifiers are shown. Each nominal square is 1.5 km per side even where an edge cell looks irregular after clipping.

There are **53 saved blocks** among 23,066 officially assigned source listings. Five fold labels occur, with **no block split between fold labels**. One of the 53 has no listing in the 12,412-row Phase 9 common sample. It is displayed neutrally, not silently given a new fold or omitted. The remaining coloured blocks use their saved assignments. Phase 8's allocation used `StratifiedGroupKFold` with seed **20261034** and a **geography-only constrained seed search**: every fold needed at least 100 Frederiksberg source listings and a largest/smallest full-fold ratio below three. No outcome, accessibility or model score selected that seed. Consequently, these are outcome-blind grouped assignments, **not randomly selected individual square locations**. The saved common-sample fold test sizes are 1,341 / 3,243 / 3,550 / 1,591 / 2,687.

## Tables and existing performance

The [methods table](../outputs/tables/final/table_validation_designs.md) (also [CSV](../outputs/tables/final/table_validation_designs.csv)) compares grouping unit, number of groups, possible neighbouring train/test observations, prediction question, and role for all four designs. The optional [performance appendix](../outputs/tables/final/table_validation_performance.md) (also [CSV](../outputs/tables/final/table_validation_performance.csv)) reads only **existing** pooled XGBoost M0/MW log-price RMSE on the same 12,412-listing common sample; it does not fill gaps by refitting. The saved M0→MW RMSE reductions are +0.00840 for random CV, +0.00422 for the 1.5 km block CV, +0.00301 for LOAO, −0.00056 for 500 m buffered LOAO, and +0.00026 for 1,000 m buffered LOAO. These changes reinforce that the incremental accessibility conclusion depends on how geographic separation is defined; they do not replace the frozen Phase 9 comparison.

## Verification and limitations

The read-only producer checks **23,144** saved assignment rows, **53** unique 1.5 km blocks, **five** block folds and random folds, **11** official held-out areas, one fold label per block, **12,412** common-sample listings across blocks, and saved 500/1,000 m exclusions covering all 11 areas. It also refuses to use an unexpected sample size in the performance appendix. Figures contain no actual Airbnb points. Official-area boundaries can be adjacent and some Airbnb coordinates are approximate; neither the square grid nor the administrative split guarantees that all retained train/test points are far apart. Frederiksberg is one municipality-sized proxy fold, not an eleventh Copenhagen district.
